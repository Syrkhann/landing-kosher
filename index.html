О проекте

Почему выбран Tailwind CSS?

Tailwind CSS позволяет быстро создавать интерфейс с помощью готовых utility-классов. Для адаптивности используются префиксы sm:, md: и lg:, поэтому один HTML-файл может подстраиваться под разные размеры экрана. Для этой лабораторной работы структура страницы полностью построена utility-классами Tailwind без собственного CSS-файла. Это удобно для быстрого прототипирования и небольших интерфейсов. Недостаток заключается в том, что HTML может становиться длинным из-за большого количества классов. В отличие от Bootstrap, Tailwind не требует использовать готовые компоненты и даёт более свободно собирать собственный дизайн.
